\section{Introduction}

\begin{frame}[fragile]{Before we start}
  Prerequisites
  \begin{itemize}
    \item basic OOP in C++ (methods, initialization, constructors)
    \item basic assembly concepts (labels, stack frames)
  \end{itemize}

  Workshop topics
  \begin{itemize}
    \item Objects, RAII
    \item Move semantics, temporaries, RVO
    \item Templates, universal references
  \end{itemize}
\end{frame}

\begin{frame}[fragile]{Conventions}
  Any assembly code shown will be x86-64, using System V ABI, compiled with -O0.

  I will sometimes refer to methods, constructors and destructors by their full demangled function name e.g.
  \mintinline{cpp}{ExampleClassName::exampleMethodName(arg1, arg2)}.

  When I say a function is \emph{called on} some chunk of memory, this means that a pointer
  to this location is passed as an argument to the function.
\end{frame}
